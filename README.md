### 🍕 [PizzaLoop](https://github.com/hugoopen/pizzaloop)
Sistema de gerenciamento de pizzaria desenvolvido em Python com interface desktop CustomTkinter e banco de dados MySQL (Aiven Cloud).



![Python](https://img.shields.io/badge/Python-14354C?style=flat-square&logo=python&logoColor=00FF41)




![MySQL](https://img.shields.io/badge/MySQL-00758F?style=flat-square&logo=mysql&logoColor=white)




![MVC](https://img.shields.io/badge/Arquitetura-MVC-00FF41?style=flat-square&logoColor=black)



- 🏗️ Arquitetura **MVC**
- 🔐 Controle de acesso por cargo (**RBAC**) com auditoria
- 🔒 Login com **bcrypt**
- 📄 Exportação de relatórios em **PDF** com ReportLab
